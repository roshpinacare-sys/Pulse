# Runbook: quota-dead (ריפו פרטי שהמכסה שלו מתה)

**תסמין**: ריצות Actions נכשלות עם אפס צעדים (jobs API: `steps: []`, conclusion=failure) — הריצה מתה לפני הצעד הראשון. קורה רק בריפואים פרטיים.

**אבחון**:
1. `GET /repos/{repo}/actions/runs/{id}/jobs` — אפס צעדים = לפני-runner.
2. הריפו פרטי? מכסת-דקות פרטיות מוגבלת (2000/חודש בתוכנית-חינם).
3. billing API לא נגיש ל-PAT fine-grained (403) — המדידה היא מהתנהגות, לא ממכסה.

**תיקון**: להעביר את החישוב לריפו ציבורי (חוק-דקות-החינם §7). הריפו הפרטי נשאר זיכרון (קבצים), לא מנוע. הכתובת-המאושרת: Autonomy (עורקים) + Pulse (דופק/מראה).

**אימות**: ריצה חדשה בריפו הציבורי success; קבצי-הזיכרון ממשיכים להתקבל (pushed_at מתעדכן).

**מניעה**: אין לקבוע cron על ריפו פרטי כנתיב-הישרדות של שום יכולת.
