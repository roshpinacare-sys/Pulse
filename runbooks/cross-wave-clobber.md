# Runbook: cross-wave-clobber (גל מקביל דורס תיקון)

**תסמין**: תיקון נמדד חי (0 צ'יפים-סגורים) ואז חוזר בדפדפן עם deploy טרי. ב-git: קומיט של גל-אחר משחזר קובץ לגרסה ישנה; הקומיט-המקורי עדיין אב בהיסטוריה.

**אבחון**:
1. `git merge-base --is-ancestor {fix-sha} origin/main` — אם אב: לא שוחזר, אלא **הוחלף** — קומיט אחר כתב את הקובץ מ-checkout מיושן.
2. `git log --follow {file}` — מציאת הקומיט-הדורס וה-trace שלו.
3. קננרי: verifier PU9 — index.html חייב ≥4 הפניות-מראה ו-0 "מקור נסגר".

**תיקון**: שחזור מ-origin (לא מ-checkout מקומי!) + שימור-הדלתא התוספת של הגל-האחר (diff head-בין-גרסאות) + push עם rebase.

**מניעה**: חוק-מיזוג-הגלים (BOOTSTRAP §3): `git pull --rebase` לפני push, תצוגה-חיה אחרי, איסור-שחזור מ-checkout מיושן.
