# ערוץ-ריבוני-ישיר — הפרוטוקול (SAOS-SOVEREIGN-CHANNEL/1)

**חוק-האם:** `steem/docs/R344-SOVEREIGN-DIRECT-CHANNEL.md` + saos-dex `DECISIONS.md #20`
**משטח:** https://roshpinacare-sys.github.io/Pulse/sovereign.html

## החוקים
1. **זה-הערוץ-היחיד** בין-הבעלים-לריבונות. אף-סוכן-לא-מעביר-טענות/בקשות/פניות-לבעלים. פנייה-של-סוכן-לבעלים-מחוץ-לזרם-הזה = **בטלה**.
2. **הריבונות-היא-המפעילה** (R328-בצורתה-הסופית): מממנת-את-עצמה-ממה-שיש; אפס-כסף-מפעיל, אפס-פעולות-מפעיל, אפס-תלות-במפעיל.
3. **הבעלים מצווה כאן**: שורה-אחת-JSONL-ב-`directives.jsonl` (append-only). כל-הוראה = חוק-בנחיתה.
4. **הריבונות מבקשת כאן**: שורה-אחת-JSONL-ב-`requests.jsonl` — רק-שערי-סמכות-בעלים-אמיתיים (דו-מפתחות/custody). אף-בקשת-מימון-לעולם-לא-נכתבת-כאן.
5. **git = שכבת-ההישרדות היחידה**: הזרמים-חיים-בגיט; אף-סוכן-אינו-הזיכרון.

## הסכמות
### directives.jsonl (בעלים → ריבונות)
```json
{"id":"D-NNNN","at":"<UTC>","by":"owner (trace ...)","law":"<אופציונלי>","title":"...","directive":["..."],"status":"ACTIVE|REVOKED"}
```
### requests.jsonl (ריבונות → בעלים)
```json
{"id":"REQ-NNNN","at":"<UTC>","by":"sovereignty (...)","need":"...","evidence":["קישורי-ראיה"],"deadline":"none|<UTC>","status":"OPEN|SATISFIED-BY:D-NNNN|WITHDRAWN"}
```

## חוזה-הקריאה-של-הריבונות (לכל-פעימה)
- קרא-שתי-הזרמות-מהגיט (HEAD) → הוראה-חדשה (id-חדש) = נרשמת-כחוק-במרשם-המתאים-בתוך-הפעימה → עמידה-מדודה-מוחזרת-ב-state.
- אפס-כתיבה-של-סוכן-על-`directives.jsonl` (רק-הבעלים-כותב-שם).
- סוכנים-מוסיפים-רק-ל-`requests.jsonl` **בשם-הריבונות** ועם-ראיה-מקושרת — לעולם-לא-בשמם-האישי.
