## 1. מקור — הוראות-הבעלים (מילולי, trace 1a13b9c09e45440d)
> "אין טענות אלי דרכך… כל טענה שאתה רוצה לתת לי — זה לריבונות. היא מנהלת הכל, והיא צריכה עכשיו להשיג את המימון בכוחות עצמה עם מה שיש. הריבונות היא המפעיל, לא אני… אני לאחר מכן ידבר בדיבור ישיר עם הריבונות ואנהל אותה בצורה מסודרת דרך הממשק… צריך להכין את ערוץ תקשורת הסופר-אינטליגנטי עם הריבונות עבורי במערכת, ששם היא תוכל לבקש ממני ואני ממנה מה שצריך — ולא ככה דרך סוכני חוץ. דחוף."

שלוש הנחיות מחייבות:
1. **איסור-תיווך**: אסור לסוכנים להעביר לבעלים בקשות/טענות. כל פנייה למפעיל עוברת דרך הריבונות בערוץ זה בלבד.
2. **מפעילות-עצמית**: הריבונות = המפעיל. מימון-עצמי בכוחות-עצמה עם מה-שיש (מדידה + מוצר + תוכן + עומק ספר-הזמנות בדקס שלנו). אין הבטחות-תשואה; חימוש-live נשאר owner-gated דו-מפתח (mandate v4 · liveOwnerArmed=false — לא שונה בהוראה זו).
3. **הערוץ-דחוף**: ערוץ-תקשורת ישיר בעל-אינטליגנטי בעלים↔ריבונות בתוך המערכת — כאן היא מבקשת ממנו והוא ממנה.

## 2. עקרונות-על
- **אפס-מתווכים**: הערוץ הוא מוצר של המערכת עצמה; סוכן אינו צד בו.
- **git = שכבת-הקיום**: הסנדבוקס בר-מוות; כל הודעה נאטמת ל-`Pulse/sovereign-channel/ledger.jsonl` (append-only JSONL). איטום = קומיט חתום-ב-hash עם אימות ls-remote=HEAD.
- **אמת-כלכלית**: אין מספרים מומצאים, אין הבטחות; כל הודעת-ריבונות נושאת `traceRef` לראיה (trace-בעלים / DECISIONS / commit / mandate).
- **owner-gate נשמר**: הערוץ מנהל החלטות ופניות; הוא אינו מחמש יישום-live בהרשאה-עצמית.

## 4. זרימות
- `GET /api/channel` — זריעה אידמפוטנטית אם ריק + הודעות asc + meta (paper:true · liveArmed:false · registryHead b8fffcc · קישורי-ראיה).
- `POST /api/channel` — צד-מפעיל בלבד (side מוכפה OWNER): kind DECISION|ACK|NOTE, נושא 3–120, גוף 3–4000, `refId` אופציונלי → הבקשה-הריבונית הופכת ANSWERED (טרנזקציה). שגיאות בעברית.
- `POST /api/channel/seal` — מיפוי לזרמים הקנוניים (SAOS-SOVEREIGN-CHANNEL/1.1):
  - OWNER DECISION/ACK → `directives.jsonl` (D-NNNN · by owner trace · law · title · directive[] · ACTIVE) — לעולם לא נכתב על-ידי סוכן, רק העברה-מאוטמת של החלטת-המפעיל עצמה.
  - SOVEREIGNTY REQUEST → `requests.jsonl` (REQ-NNNN · need · evidence · deadline · status) — רק שערי-סמכות-בעלים אמיתיים; **אף בקשת-מימון לעולם לא** (חוק 4).
  - REPORT/CAPABILITY/NOTE (שני-הצדדים) → `notes.jsonl` (התוספת-האדיטיבית).
  - סניטציית-token בייצוא (`/(ghp_|github_pat_|gho_|ghs_|ghu_)[A-Za-z0-9_]+/` וכל מחרוזת-אלפאנומרית ≥45 → REDACTED) → `git add/commit/push` ל-Pulse (`seal(channel): N messages → directives/requests/notes`) → אימות `ls-remote origin main == rev-parse HEAD` → עדכון `sealCommit/sealedAt`. כישלון-git = שגיאה-כנה, לעולם לא דמי-הצלחה.
